# Object-Oriented Programming Experiments

This folder contains experiments related to C++ OOP features.

## Files

- `vtables.cpp` - Virtual table (vtable) exploration
- `diamond_prob.cpp` - Diamond problem in multiple inheritance
- `friend_Func.cpp` - Friend functions and classes
- `constr_test.cpp` - Constructor initialization order

## Concepts

- Virtual function tables (vtables)
- Multiple inheritance
- Friend functions/classes
- Constructor member initialization order
