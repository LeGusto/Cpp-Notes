# Performance Benchmarks

This folder contains performance benchmarks comparing different C++ features and optimization strategies.

## Files

- `type_test.cpp` - Integer type performance comparison (CPU-bound)
- `red_vs_acc.cpp` - `std::accumulate` vs `std::reduce` comparison (memory-bound)
- `volat_opt.cpp` - `volatile` keyword and optimization effects

## Experiments

See `experiments.md` for detailed methodology, results, and analysis of the benchmarks.
