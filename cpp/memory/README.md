# Memory & Alignment Experiments

This folder contains experiments related to memory layout, struct padding, alignment, and cache effects.

## Files

- `pad_test.cpp` - Tests struct padding and alignment performance
- `pad_test_packed.cpp` - Tests structs with `#pragma pack(1)` (no padding)
- `memory_test.cpp` - Memory layout experiments
- `cache.cpp` - Cache-related experiments

## Concepts

- Struct padding and alignment
- Cache line effects on performance
- Memory layout optimization
